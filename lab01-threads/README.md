# Лабораторная 1 — работа с потоками

Программа создаёт N потоков (N — аргумент командной строки), каждому передаёт его
порядковый номер, каждый поток печатает одну строку, программа дожидается
завершения всех потоков.

```
./build/lab01-threads/lab01-threads 5
```

## Ключевые моменты

- `std::jthread` — join выполняется в деструкторе, явный `join()` не нужен.
- Номер потока передаётся по значению, а не ссылкой на переменную цикла.
- `std::osyncstream` отдаёт строку в `cout` одним куском, поэтому вывод разных
  потоков не перемешивается.
- Создание потока может бросить `std::system_error` — это обрабатывается.
